# Аналитика

Яндекс.Метрика, счётчик **113576831**. Номер задан один раз, в `apps/web/src/lib/metrika.ts`;
`vite.config.ts` вставляет из него загрузчик и noscript-пиксель в `index.html`.

Счётчик инициализируется с `defer: true`: каждый просмотр, включая первый, отправляет
`Layout` при смене маршрута. Из адреса страницы организатора токен вырезается
(`/p/{slug}/admin/{token}` → `/p/{slug}/admin`): ссылка даёт права организатора и в Яндекс
не уходит.

**Имена целей менять нельзя, не поменяв условие цели в Метрике**: цель ищет точное совпадение строки.
Все цели типа «JavaScript-событие» (`reachGoal`).

| Цель | Когда | Параметры |
|---|---|---|
| `poll_create` | встреча создана | `days`, `times` (0 — весь день) |
| `poll_respond` | участник сохранил ответ | `slots`, `edit` (1 — правка своего ответа) |
| `poll_confirm` | организатор назначил время | `participants` |
| `ics_download` | нажата «Добавить в календарь» | — |
| `theme_toggle` | смена темы | `theme`: лик, в который переключились |
