# CAL

Планировщик групповых встреч. Организатор предлагает дни и время, участники нажимают, когда могут, лучший вариант находится сам. Без регистрации, каждый экран помещается на телефоне без скролла.

**[cal.borozdov.ru](https://cal.borozdov.ru)**

## Что делает

Три экрана, у каждого одно действие.

**Создание.** Четыре шага: что планируем, какие дни, во сколько, сколько длится. Дни выбираются плиткой на две недели вперёд, не больше семи. Время выделяется протяжкой пальца по линейке часов 00–23 или вписывается цифрами: `9` превращается в `09:00`, `1030` в `10:30`. Промежутков сколько угодно, каждый нарезается на варианты по длительности встречи. Над кнопкой видно, что получится: «9 вариантов в день: 10:00, 10:30…».

**Голосование.** Участник пишет имя и нажимает время, когда может. Сверху вкладки дней, под ними сетка времени выбранного дня. Цифра в ячейке, это сколько человек уже могут, лучший вариант отмечен рамкой и назван словами: «СБ, 26 сентября · 14:30, могут все». Есть «весь день» одной кнопкой и «ничего не подходит», чтобы отказ тоже учитывался. Ответ можно поменять, вернувшись по той же ссылке.

**Организатор.** Та же сетка с ответами всех участников, лучший вариант уже выбран, остаётся одна кнопка «Назначить». Две ссылки на копирование: для участников и для организаторов, вторая даёт те же права. После назначения все видят дату, время, кто придёт, и кнопку «Добавить в календарь» с файлом `.ics`.

Аккаунтов нет. Организатор узнаётся по секретной ссылке, участник по имени и записи в `localStorage`. Встречи, созданные на устройстве, лежат в меню «Мои встречи», чтобы ссылка организатора не терялась.

Модель вариантов и одноэкранный интерфейс выбраны по разбору Doodle, Rallly, When2meet, Crab Fit и Timeful: сетка с протяжкой по получасам на телефоне путается со скроллом, а вопрос «можешь во вторник в 19:00» понятен сразу.

## Ограничения

| Что | Предел |
|---|---:|
| Дней во встрече | 7 |
| Вариантов времени в день | 48 |
| Длительность встречи | 5 мин – 12 ч |
| Название | 80 символов |
| Создание встреч с одного IP | 20 в час |

При 48 вариантах сетка уплотняется до шести колонок, цифры в ячейках прячутся, количество ответов показывает заливка.

## Адреса

| Адрес | Что там |
|---|---|
| `/` | создание встречи |
| `/p/{slug}` | голосование участника |
| `/p/{slug}/admin/{token}` | страница организатора |
| `/kitchen-sink` | рендер всех примитивов |

## API

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/polls` | создать встречу, вернуть `slug` и `adminToken` |
| `GET` | `/api/polls/{slug}` | встреча со всеми ответами |
| `POST` | `/api/polls/{slug}/respond` | сохранить ответ участника |
| `GET` | `/api/polls/{slug}/ics` | файл календаря назначенной встречи |
| `GET` | `/api/polls/{slug}/admin/{token}` | проверить ссылку организатора |
| `POST` | `/api/polls/{slug}/admin/{token}/confirm` | назначить вариант |
| `POST` | `/api/polls/{slug}/admin/{token}/unconfirm` | вернуть сбор ответов |

Ответ всегда `{ data }` или `{ error: { code, message } }`. Схемы запросов общие для клиента и сервера, лежат в `packages/shared` на Zod.

## Стек

| Слой | Выбор |
|---|---|
| Язык | TypeScript, `strict` |
| Монорепозиторий | npm workspaces: `apps/web`, `apps/api`, `packages/shared` |
| Фронтенд | React 19, React Router 7, Vite |
| Бэкенд | Express 5, Zod |

| Стили | CSS Modules плюс CSS-переменные ролей |

Ликов два, тёмный ОБСИДИАН и светлый ТИТАН. Цветовых значений вне `tokens.css` нет, в модулях только `var(--role)`. Любое число моноширинное с `tabular-nums`. Все контролы свои: выбор дней, линейка часов, ввод времени.

## Запуск

Нужны Node.js 22 и Docker для локального Postgres.

```bash
npm install
docker compose up -d
cp apps/api/.env.example apps/api/.env
npm run prisma:generate --workspace apps/api
npm run prisma:migrate:deploy --workspace apps/api
npm run dev
```

Фронтенд откроется на [localhost:5180](http://localhost:5180), API на порту 4000, Vite проксирует `/api`.

| Команда | Что делает |
|---|---|
| `npm run dev` | API и фронтенд вместе, с перезапуском |
| `npm run build` | сборка всех пакетов |
| `npm run typecheck` | `tsc --noEmit` во всех пакетах |
| `npm run lint` | ESLint |

## Структура

```
apps/
  web/src/
    features/create/   экран создания: дни, линейка часов, промежутки
    features/poll/     голосование, организатор, назначенная встреча
    primitives/        кнопки, поля, ввод времени, не знают о встречах
    routes/            каркас, «Мои встречи», 404, kitchen-sink
    theme/             токены и переключатель лика
  api/
    prisma/            схема и миграции
    src/domains/polls/ создание, ответы, назначение, .ics
packages/
  shared/              схемы Zod и общие типы
```

Встреча хранит дни и список времён начала. Вариант, это пара `день:минута`, весь день кодируется пустым списком времён. Ответ участника, это множество таких пар. Сетку, счётчики и лучший вариант клиент считает сам из ответа `GET /api/polls/{slug}`.

## Деплой

Один контейнер отдаёт и SPA, и API, рядом отдельный Postgres. Домен и сертификат держит общий Caddy на сервере. Миграции применяются при старте контейнера. Подробности и команды обновления и бэкапа в [`DEPLOY.md`](DEPLOY.md).
